# 了解 Python 的常见面试题

1. Python 的可变对象与不可变对象有什么区别？为什么默认参数不要用 `[]` / `{}`？
2. `==` 和 `is` 的区别是什么？小整数与短字符串的缓存（intern）会带来哪些面试坑？
3. 列表、元组、集合、字典各自适用什么场景？时间复杂度上查找、插入有何差异？
4. 什么是迭代器、可迭代对象、生成器？`yield` 解决什么问题，和一次性返回大列表比有何取舍？
5. 装饰器的本质是什么？带参数的装饰器、类装饰器怎么写？如何保留原函数的 `__name__` / 签名？
6. GIL 是什么？它对多线程 CPU 密集与 I/O 密集任务分别意味着什么？何时用多进程、异步（asyncio）？
7. `*args`、`**kwargs`、仅限关键字参数、位置仅限参数（`/`）分别解决什么？如何设计清晰的函数签名？
8. 深拷贝与浅拷贝的区别？可变嵌套结构下如何避免「改 A 却动到 B」？
9. 异常体系怎么用？何时自定义异常、何时用 `else` / `finally`？上下文管理器（`with`）解决什么问题？
10. 谈谈你对 Python 内存与对象模型的理解：引用计数、循环引用与 GC、`__slots__` 的用途与代价。
