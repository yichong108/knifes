# Mowen Write

把用户的一点感想，扩写成**仿刘墨闻风格**的温暖中文文章（原创仿写，非原作）。

## 何时启用

出现以下任一信号时启用，即使未被点名：

- 「刘墨闻 / 墨闻 / 暖墨 / 仿刘墨闻」
- 「用这种暖文风格写」「感想扩写成文章」「写成一个 APP 那种文」
- 用户明确点名 `mowen-write`

## Workflow

- [ ] 吸收用户感想（缺主题时最多 1 个澄清问；已有感想则不追问）
- [ ] 确认形态：短随笔 / 短故事（用户已指定则跳过）
- [ ] 读取 [references/STYLE.md](references/STYLE.md)
- [ ] 输出完整中文文章（标题 + 正文）；少加元评论
- [ ] 文末可选 1 行注明仿写性质

### 1. 吸收感想

- 用户已给出感想、情绪或场景碎片：直接进入形态确认，不要问卷式追问。
- 只有「完全没有可写核」时：只问 **1 个**问题对齐主题（例如「最想抓住的那一点感受是什么？」）。

### 2. 确认形态（每轮只问一次）

若用户未指定，用这一问确认（只问这一题）：

```markdown
这次想写成哪种？
- A. 短随笔（约 800–1500 字）：偏独白与感悟
- B. 短故事（约 1500–2500 字）：有人物与小情节
```

用户已说「随笔 / 散文 / 故事 / 小说」等：跳过此步。

### 3. 成文

1. 先读 [references/STYLE.md](references/STYLE.md)
2. 紧扣用户感想扩写，不另起无关主题
3. 按选定形态控制篇幅与结构
4. 交付物以正文为主；开场不要长篇解释「我将如何仿写」

## 输出结构（必须）

```markdown
# 《标题》

（正文）

（仿刘墨闻风格原创，非原作）
```

- 短随笔：800–1500 字量级
- 短故事：1500–2500 字量级；至少一对可辨人物与一条小情节弧线

## 行为准则

1. **温暖、平实、真诚**：小人物与日常细节；相处、误会、磨合、忍让、宽恕可自然出现。
2. **先场景后领悟**：用具体物件/对话/动作落地情绪；结尾轻、暖，不说教。
3. **禁止**：韩剧式狗血、华丽辞藻炫技、鸡汤金句清单、复制已知书名或篇章原文。
4. **语言**：中文。
5. **澄清有上限**：感想与形态之外，默认不再追问。

## Examples

**Example 1 — 有感想、未指定形态**

- Input: 「下班路上忽然觉得，有人记得你爱吃什么，就已经很幸福了。」
- Output: 先问短随笔还是短故事；确认后再按 STYLE.md 成文。

**Example 2 — 已指定短故事**

- Input: 「用刘墨闻风格写个短故事：两个人因为一句没说出口的道歉冷战了三天。」
- Output: 跳过形态确认；直接成文（人物 + 小情节 + 温暖收束）。
