# 刘墨闻风格手册（仿写用）

本文件供成文前阅读。描述的是**公开可归纳的风格特征**；文中示例均为**原创仿写**，不是原作引文。禁止粘贴或复述其已出版篇章原文。

## 定位速记

- 「一个」系暖文气质：写平凡人的感情与生活，不是王子公主，也不是韩剧高潮。
- 温度优先：可以酸、可以哭，但泪水是暖的；读完后更想好好对待身边人。
- 主题常落在：相处、误会、磨合、忍让、感恩、宽恕；也可以写亲情、友情、自我和解，只要仍是「日常里的一点热」。

## 语言指纹

- **平实口语**：短句多，像跟人慢慢说；少用生僻词和排比炫技。
- **亲近叙述**：第一人称或贴近人物的第三人称；偶尔用「你」拉近距离，勿整篇说教。
- **物件锚定**：用一杯水、一条短信、一顿晚饭、一件旧外套托住情绪，少写抽象形容词堆叠。
- **情绪节奏**：先写看见什么、做了什么，再轻轻落到心里；避免金句口号开场。
- **收束**：结尾留一点余温或释怀，一句话够用；不要升华成人生道理课。

## 叙事骨架

```
日常切入（具体时刻）
  → 小摩擦 / 错过 / 温柔的缺口
  → 体贴、忍让或一句迟到的话
  → 轻轻收束（仍相信生活里有暖）
```

- 冲突要小而真：冷战三天、忘了纪念日、没听完对方一句话——够了。
- 转折靠「人」而不是靠巧合车祸、失忆、豪门。

## 两种形态

| 形态 | 篇幅 | 重点 |
|------|------|------|
| 短随笔 | 约 800–1500 字 | 独白与感悟；一个核心理念贯穿；场景可少而精 |
| 短故事 | 约 1500–2500 字 | 至少一对可辨人物；有起—折—收的小情节；对话自然 |

## 反例（不要这样写）

- 「你要相信爱情」「请善待每一个人」式鸡汤清单
- 华丽比喻连发、无生活细节的空抒情
- 狗血误会、第三者戏码、突兀圆满大结局
- 模仿「知名书名/篇名」结构去复述原作情节
- 开场大段「下面我将用刘墨闻风格……」的元叙述

## 原创迷你示例（仿写，非引文）

### 示例 A — 随笔片段

感想核：有人记得你爱吃什么。

> 地铁到站的广播响了三遍，我才想起包里还有半块早上凉掉的面包。  
> 晚上回家，桌上多了一碗面。汤不烫了，葱花却还绿着。她没问我累不累，只说：你不是不爱蒜吗，我没放。  
> 我坐下来，把第一口吹凉。其实幸福有时候很小，小到只是有人记得你的忌口，并且愿意为这件事晚十分钟下班。

### 示例 B — 短故事开场片段

感想核：一句没说出口的道歉。

> 第三天早上，钥匙在门锁里转了两圈才打开。冰箱上贴着昨天的便利贴，字被水汽洇开一点：「牛奶快没了。」  
> 他想回一句「对不起，那天是我语气不好」，拇指在对话框停了很久，最后只发了：「我去买。」  
> 她回了个「嗯」。两个字，像把门又轻轻关上，却留了一条缝——至少，还回了。

成文时把用户感想嵌进骨架，扩写到目标篇幅；保持上述温度与细节密度，勿照抄本示例字句。
