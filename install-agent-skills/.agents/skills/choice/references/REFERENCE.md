# Choice 参考

`SKILL.md` 放流程与输出骨架；本文件补充分类、探询维度、检查清单与反例。

## 常见利害域

| 域 | 典型场景 | 高风险信号 |
|----|----------|------------|
| 资金 | 付费、转账、合约、锁仓 | 不可退、自动续费、授权无限额度 |
| 数据 | 迁移、删除、共享、训练上传 | 无备份、权限过宽、明文密钥 |
| 代码/运维 | 生产变更、force push、删资源 | 不可逆、无回滚、影响他人 |
| 身份/权限 | OAuth、管理员、API Key | 长期凭证、写入权限、第三方可见 |
| 合规/声誉 | 公开发布、爬取、对外承诺 | 违法违规、不可撤回的公开内容 |
| 时间/机会 | 延期、重做、绑定供应商 | 错过窗口、高切换成本 |

## 阶段一：探询维度清单

确认前至少覆盖仍不清楚的维度（已由用户说清的可跳过）。  
**用法**：这是内部选题清单，不是发给用户的问卷——每轮只挑其中**最阻断**的 1 题问出口。

| 维度 | 要问清什么 | 示例问题 |
|------|------------|----------|
| 利益方 | 谁受益、谁担风险、谁被连累、谁能否决 | 还有谁的数据/账号/声誉会被波及？ |
| 决策者立场 | 真正目标、优先级、不可接受结果 | 更在意速度、成本，还是可逆性？ |
| 执行者角度 | 谁操作、技能与权限是否够 | 你是否有生产权限？谁来回滚？ |
| 受影响方角度 | 同事、客户、用户、供应商会怎样 | 其他人是否已基于现状做了依赖？ |
| 合规/安全角度 | 政策、合同、密钥、审计 | 是否涉及对外承诺或受监管数据？ |
| 背景事实 | 已发生什么、当前状态 | 已经推送了吗？有没有备份？ |
| 资源约束 | 时间、预算、工具、人力 | 最晚什么时候必须决定？预算上限？ |

### 逐问对话要点

- 每轮 = 吸收上一答（可选 1 句）+ **恰好 1 个问题**
- 优先问：答了就能缩小方案空间、或直接挡住危险操作的问题
- 用户答不清时：把同一缺口改成更小、更具体的一问，不要改成「下面几个都答一下」
- 缺口齐了再出「我目前的理解」摘要；探询中途不要用分组问题清单打断

### 探询反例

- 一上来就给 A/B/C 方案对比（跳过确认）
- 只问「你确定要做吗？」而不问利益方与资源
- 一次抛出多个问题或按维度列问卷（即使用户说「你可以一起问」也优先逐问，除非对方明确要求一次性列全）
- 预告「我还要问利益方、权限、备份……」却不先问当前最关键的一题
- 把猜测写成「你的情况是…」却不标待确认

## 方案枚举检查清单（阶段二）

写方案前自检：

- [ ] 用户已确认阶段一的理解（或明确补齐关键缺口）
- [ ] 是否包含「暂缓 / 不作为」（若它确实是选项）
- [ ] 是否包含「更小步、可逆」的中间方案
- [ ] 每个方案是否写清退出成本（反悔要花什么）
- [ ] 是否标明依赖的未知信息（别把假设写成事实）
- [ ] 高风险坑点是否都有对应处理动作
- [ ] 每条利害是否都有「为何会出现」

## 坑点与利害成因写法

每条利害/坑点 = **结果** + **为何会出现**（一句机制）+ 可选的处理动作。

**好：**

- 🔴 高：生产库直接 `DROP` 且无近期备份 → 数据可能永久丢失 —— **为何会出现**：删除后磁盘上的数据会被覆盖/回收，没有快照就无法还原；先快照再操作，失败则从快照恢复
- 🟡 中：年付后 7 天外通常不可退 → 先确认 7 天内是否必用核心功能 —— **为何会出现**：商家按服务条款设短冷静期，过期即视为已消费完整周期
- 利害：授权「无限额度」给第三方 —— **为何会出现**：对方可在未再确认的情况下反复发起扣款/转账，额度上限形同虚设

**差：**

- 「有一定风险，请谨慎」
- 「可能会有问题」
- 「注意安全与合规」（无具体触发条件、成因与动作）
- 「会造成损失」（只报结果，不说因果链条）

## 话术边界

- 可以：多方探询、陈述利害、给默认推荐、列出确认项
- 不要：未确认就给完整方案；伪装成用户已做决定；用恐吓逼选；隐瞒更安全但更慢的选项
- 涉及法律/医疗/投资等专业结论时：标明「非正式建议」，引导寻求合格专业意见，同时仍把已知利害说清楚

## 与普通建议的区别

| 普通建议 | Choice |
|----------|-------|
| 直接给「你应该做 X」 | 先多方探询并确认，再并列方案与利害 |
| 风险一笔带过 | 风险分级 + 成因 + 可执行处理 |
| 马上执行危险操作 | 先探询 → 再方案 → 用户选定后再执行 |
| 只站在提问者一侧 | 覆盖利益方、立场、资源等多角度 |
