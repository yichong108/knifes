# 刘墨闻风格手册（小册子 · 偏散文）

成文前必读。描述公开可归纳的风格特征；示例为**原创仿写**，禁止粘贴或复述已出版原作原文。

本 skill 章节**默认散文**，只按本手册写；不要夹带分析报告，也不要默认写成短篇故事。

## 定位速记

- 「一个」系暖文气质：平凡人的感情与生活。
- 温度优先：可以酸、可以哭，泪水是暖的。
- 小册子里更偏：**独白、回望、一点点想通**——像夜里把灯拧暗后跟人慢慢说。
- **说的时候要顺**：一口气能听懂、听下去，不磕绊、不跳台。

## 流畅 · 自然 · 连贯（硬性）

成文后默读一遍，须同时满足：

1. **句句接气**：上一句的尾，能自然落到下一句的头；少用互不相关的短句并排砸人。
2. **段段有桥**：换段靠情绪或物件轻轻带过去，不要无声硬切到另一个场面。
3. **章内一条气**：从头到尾像同一个人在同一段心情里说话；中途不要换腔、换无关主题。
4. **跳跃也要软**：允许从地铁想到晚饭，但中间要有一句心上的线（「想起…」「于是…」「那天也是…」之类口语衔接），禁止蒙太奇式无过渡跳切。
5. **长短错落**：短句多，但要夹一点稍长的口气，像说话；通篇电报体、通篇排比都不自然。

**差（碎、硬）：**  
「灯坏了。面包凉了。她没说话。我坐下。幸福很小。」

**好（顺、像人说）：**  
「灯坏了一根，亮的那根也在抖。我想起包里还有半块凉掉的面包，没吃。晚上回家，桌上多了一碗面，她没问我累不累，只说蒜没放。我坐下，把第一口吹凉——幸福有时候就这么小。」

## 散文优先（默认）

- **我看见 → 我心里动了一下 → 轻轻落下**：以感受为主线，情节只是碎光。
- 场景可以挪，但靠情绪连，读者不觉得被拽着换台。
- 对话可有，一两句够用；嵌在叙述里，不要突然变成剧本。
- 人物可以模糊成「她 / 他 / 你」，不必塑造完整人物小传。
- 结尾留白、余温即可，不要「故事讲完了」式收官。

## 语言指纹

- **平实口语**：像跟人慢慢说；少生僻词和排比炫技。
- **亲近叙述**：第一人称最自然；偶尔「你」；勿整篇说教。
- **物件锚定**：一杯水、一条短信、一顿晚饭、一件旧外套托住情绪。
- **情绪节奏**：先写看见什么、做了什么，再轻轻落到心里；避免金句口号开场。
- **收束**：一句话余温；不要升华成人生道理课。

## 节奏（散文用）

```
具体时刻 / 物件
  → （口语轻轻一转）心里那一点酸或暖
  → 旁及相关的日常碎片（可选，仍要接气）
  → 轻轻收住（不说教）
```

小摩擦、错过、温柔的缺口可以出现，但当作**感受的由头**，不是要讲完一出戏。

## 形态

| 形态 | 何时用 | 篇幅 | 重点 |
|------|--------|------|------|
| **散文 / 随笔（默认）** | 一律默认 | 约 800–1500 字 | 独白与感悟；场景少而精；**一口气读顺** |
| 短故事 | 仅用户明确要求 | 约 1500–2500 字 | 可辨人物 + 小情节弧；仍要顺读 |

## 反例

- 分析报告、固定小节、利弊表
- 鸡汤清单、华丽空抒情
- 碎句堆砌、硬跳切、作文腔「不禁想到」「与此同时」
- 默认写成多幕短剧、强反转、大结局
- 「下面我将用刘墨闻风格……」

## 原创迷你示例（散文片段，仿写非引文）

> 地铁到站的广播响了三遍，我才想起包里还有半块早上凉掉的面包。  
> 晚上回家，桌上多了一碗面。汤不烫了，葱花却还绿着。她没问我累不累，只说：你不是不爱蒜吗，我没放。  
> 我坐下来，把第一口吹凉。其实幸福有时候很小，小到只是有人记得你的忌口，并且愿意为这件事晚十分钟下班。

成文时围绕该章题目扩写成完整散文；写完默读，不顺的地方改顺，勿照抄示例字句。
