# 单章写法

每章 = **一篇刘墨闻风格散文**，且必须挂在整册线索上。旧分析框架一律不用。

## 默认：散文

1. 成文前读 [STYLE.md](STYLE.md)
2. 以「我」的看见与感受为主：一个瞬间、一件物件、一句没说完的话
3. 细节要具体（日常物件），情绪要克制；收束留余温、不说教
4. **写完默读**：句段接气、章内一口气顺；不顺就改，再定稿
5. 篇幅约 800–1500 字
6. **不要**默认写成短篇小说

仅当用户明确说「写成故事 / 小说」时，再改用短故事形态。

## 章内流畅（硬性）

- 像同一个人把一件心事说完，中途不换台、不堆互不相关的短句
- 换场景用口语轻轻带（想起、于是、那天也是…），禁止无过渡硬切
- 禁止电报体排比、作文转场词硬接
- 细则与正反例见 [STYLE.md](STYLE.md)「流畅 · 自然 · 连贯」

## 章与章的关联（硬性）

整册不是「同主题下的互不相关散文合集」，而是**一本有前后气口的小书**。

1. **先定线索，再拆章**  
   开写前想清一条贯到底的线：同一种等待、同一段关系、同一件放不下的物件、同一种说不清的心事。各章题目是这条线上的不同停顿，不是另起炉灶。

2. **后章要接前章**（至少做到一种，鼓励多种并用）  
   - **情绪递进**：闷 → 更闷 / 松一点 / 想通一点，读得出变化  
   - **物件回声**：前章出现的面、短信、旧外套等，后章再次遇见或想起（变一点角度即可）  
   - **话未说完**：前章停住的那句、那个人，后章继续碰，或终于碰不到  
   - **时空相邻**：同一段日子的前后、同一条回家的路、同一个夏天的两头  

3. **目录要像一条路**  
   章题并列读下来，应能感到顺序有意义；打乱顺序会别扭，就说明关联做对了。

4. **禁止**  
   - 各章只共享大主题词，场景与心事毫无呼应  
   - 章章换一套全新人物与冲突，读完像杂志专栏拼盘  
   - 用「上一章我们谈到…」这种作文过渡句硬接（要用意象与情绪自然接）

## 绝对不要

- 背景 / 方法 / 取舍 / 利益方 / 改进方向
- 利弊表、对比表、要点清单式「分析」
- 学术腔、鸡汤金句清单、元叙述
- 复述原作情节或篇名结构

## 题目怎么落笔

- 章题可以是一个感受、一个瞬间、一句没说出口的话
- 单章读完像短散文；**连着读**应感到在走同一条心事

## 增补或改某一章时

动一章，扫一眼前后章：线索是否断了？物件/情绪回声是否还在？**接缝读起来顺不顺**？断了或不顺就顺手改通，再 commit。
