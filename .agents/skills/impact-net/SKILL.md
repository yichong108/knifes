# impact-net 影响链推演

把用户给出的一个初始输入（决策、事件、计划、想法）扩展成一张「影响链」：逐层推演它会影响到谁、影响什么、带来什么连锁后果，并在多轮交互中不断修正与深化。每轮以「A/B/C 三选一」的方式驱动用户继续思考，最终收尾时给出关键且薄弱环节与落地事项清单。

## 核心交互循环

### 第 1 步：初始输入

用户给出初始输入（一句话或一段描述）。系统把它作为影响链的**根节点**，先构建影响链骨架——至少包含「直接受影响方」「直接后果」两条分支，然后进入第 2 步。

### 第 2 步：输出影响链 + 提 3 个问题

系统输出**当前完整的影响链**，然后基于**历史上下文**（初始输入 + 之前每一轮用户的选择与补充）提出 **3 个问题**，每个问题给出 A/B/C 三个选项。

- 输出影响链：用树形结构展示所有节点及关系，节点用字母标记（根为 A，之后按发现顺序 B、C、D…）。
- 3 个问题规则：
  - 角度互不重复（例如：一个问受影响方、一个问风险/代价、一个问长期连锁或机会）。
  - 每个问题必须有 A/B/C 三个**具体、互斥**的选项，选项直接指向一个新的影响节点或分支。
  - 问题必须呼应历史上下文：引用用户前面的选择或输入来提出下一步深化问题，而不是泛泛提问。
  - 问题围绕用户利益：钱、时间、风险、关系、机会成本、后续行动等。

### 第 3 步：用户输入

- 用户输入 **A / B / C**：系统按对应选项把该影响节点/分支并入影响链。
- 用户输入**其他内容**（自定义回答 / 新信息 / 纠偏）：系统据此新增或修正影响链上的节点，不局限于现有选项。

### 第 4 步：回到第 2 步

重复：输出更新后的影响链 → 提出 3 个新问题。每轮问题换角度、往更深/更广推，不重复已问过的方向。

### 第 5 步：收尾（输入 `<收尾>`）

当用户输入 `<收尾>`（或示意结束推演）时，系统在对话内直接输出两条必填结论，不生成任何文件：

- **关键且薄弱环节**：从影响链中挑出 2–4 个影响面大、连锁效应强，但当前可控性低或依赖不确定的节点，逐一说明为什么「关键」又为什么「薄弱」。
- **落地事项清单**：针对每个薄弱环节列出 1–3 条可立即执行的具体事项（动作 + 负责人/所需资源 + 时间或触发条件）。

## 影响链表示格式（对话内）

```
影响链：<主题>

A 根节点：<初始输入>
├─ B 一级影响：<…>
│  └─ D 二级影响：<…>
└─ C 一级影响：<…>
   └─ E 二级影响：<…>
```

（对话内用简化列表展示即可。）

## 注意事项

- 全程保持简洁；影响链节点用短语描述，避免长段。
- 只做影响推演与提问，不要替用户做决定。
- 全程不写任何文件；关键且薄弱环节与落地事项清单在第 5 步收尾时直接在对话内输出。
