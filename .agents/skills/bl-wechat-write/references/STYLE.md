# 高分享 / 高阅读 / 高点赞 公众号文风

仿写的是微信里**长期好传、好读、好赞**的一类中文图文气质，不是某个具体账号的原文搬运。  
有本号历史高互动稿时：语气、人称、常用意象以旧稿为准，本文件作结构与节奏底线。

**硬性底线：写成人话，不要 AI 味。** 宁可糙一点、散一点，也不要整齐、正确、空。

## 气质总则

- **像朋友把一段心事说完**，不是讲师做课件，更不是模型在交差。
- **先场面，后道理**；道理要短，场面要具体。
- **被看见 > 被教育**：读者点赞往往因为「写中我了」，不是因为金句清单。
- **可转赠**：文中至少有 1–2 句，读完想原话转给某个人。
- 手机阅读：段短、行疏、小标题少而准（0–4 个）。
- **句子长短不齐、段落有轻有重**；故意避开「每段差不多长、每点都对称」的机器感。

## 去 AI 味（成文必过）

### 禁止出现的句式与口气

写出或改写时，**直接删掉**下列痕迹（含近义变体）：

| 类型 | 典型烂句（禁） |
| --- | --- |
| 时代开场 | 「在这个快节奏的时代」「随着社会的发展」「在当今社会」 |
| 正确废话 | 「值得注意的是」「不可否认」「从某种意义上说」「本质上」「归根结底」 |
| 汇报腔 | 「首先…其次…最后…」「综上所述」「总而言之」「我们应该」 |
| 伪深刻 | 「深层原因」「内核」「底层逻辑」「人生课题」连发 |
| 对称排比 | 「不是A，是B；不是C，是D」整段堆砌；「既要…也要…更要…」 |
| 鸡汤收尾 | 「愿你…」「愿我们…」「希望这篇文章能帮到你」「请记得善待自己」 |
| 互动硬广 | 「点赞在看三连」「欢迎留言区聊聊」「收藏这篇，下次用得上」 |
| 说明书腔 | 「接下来我将从三个方面」「下面分三点展开」 |

### 要像人写的，而不是像生成的

- **一个具体细节顶十句感悟**：物件、时间点、半句话、身体反应。
- **允许一点口语杂质**：省略、倒装、重复、欲言又止；不要每句都语法圆满。
- **洞察最多点到为止**：同一层意思不换三种金句再说一遍。
- **少用破折号解释、少用「：」下定义**；能写成一句白话就写成一句白话。
- **不要万能假对话**：避免整篇「Ta 说 / 我说」模板对白；对话要短、要像真的说过。
- **结尾留白**：停在画面或一句实话上，不要升华成人生宣言。

### 成文后「AI 味」自检（不过关就改）

- [ ] 删掉所有「首先/其次/最后」「总之」「综上所述」
- [ ] 开头不是「在这个…的时代」或主题定义句
- [ ] 没有连续三段结构对称、字数差不多的「道理段」
- [ ] 没有「愿你」「希望帮到你」式收尾
- [ ] 文中能指出 **至少一处** 只有这篇才有的具体场景（换一篇就不能照搬）
- [ ] 朗读时像在说话，不像在念提纲

## 结构骨架（默认）

1. **开篇钩子（前 3 段内）**  
   一个可感的瞬间：对话、动作、物件、身体反应。不要空喊主题，不要时代背景开场。
2. **拉近（认同）**  
   点出「很多人其实也…」，让读者对号入座；避免一上来就下结论。
3. **展开（2–4 个节拍）**  
   每个节拍一个小场景或一层转折；可穿插一句短洞察，但不要连续说教，不要三点并列展开。
4. **加深（可选）**  
   把表面矛盾翻到更真的一层（例如吵的不是家务，是被忽视）。
5. **收束**  
   轻、暖、留白；给一个可带走的态度或一句可转发的话。  
   **不要**：催赞、愿你、人生升华、三点总结。

## 语言指纹

| 要 | 不要 |
| --- | --- |
| 日常口语、短句与长句交错 | 公文腔、鸡汤排比、AI 汇报腔 |
| 具体名词（未读红点、凉掉的粥、工位耳机） | 抽象空转（格局、赋能、底层逻辑连发） |
| 克制抒情，情绪坐在细节上 | 煽情形容词轰炸、感叹号连打 |
| 「你/我们」拉近距离 | 高高在上的「你们要懂得」 |
| 结尾余味 | 总结三段论 + 行动号召清单 |
| 偶尔不工整、留一点毛边 | 段段整齐、句句金句、处处正确 |

## 为「分享 / 阅读 / 点赞」服务的写法

- **分享**：文中埋「转给某人」的自然理由（「适合转给总说没事的人」藏在叙述里，不写成营销备注）。
- **阅读**：每屏都有推进；删掉重复感悟；小标题只在真的换层时用。
- **点赞**：写出「被理解感」；避免贬低读者智商或制造对立骂战。

## 篇幅与版式

- 默认 1200–2200 字。
- 一段 1–4 句为宜；重要句可单独成段。
- 标题与开篇不要重复同一句话硬拗。
- 可用极少量「……」「——」制造停顿；不要整篇省略号卖惨，也不要破折号解释成说明书。

## 原创与边界

- 主题可贴近常见爆款母题，**情节、比喻、句子必须新写**。
- 不抄袭、不拼接某篇爆款原文。
- 不涉及违禁、虚假健康承诺、谣言。
- 不假装引用「本账号后台：阅读 10 万+」等未经验证数据。

## 成文自检（发出前过一遍）

- [ ] 开头 3 段内有画面，不是定义主题、不是时代开场
- [ ] 至少一处具体场景，不是纯议论
- [ ] 有一句读完想转发的话
- [ ] 结尾不催赞、不硬广、不「愿你」
- [ ] 删掉所有「总之」「综上所述」「我们应该」堆砌段
- [ ] 通过上文「去 AI 味」自检，读起来像人写的
