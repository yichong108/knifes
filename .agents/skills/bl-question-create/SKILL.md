# bl-question-create

向 `问题系统/问题列表.md` 在表格顶部追加一行问题记录（日期自动填当天），并新建对应的问题 md 文件；问题列使用 Markdown 链接，点击可跳转；状态列为 checkbox。

## 目标文件

| 用途 | 路径 |
| --- | --- |
| 问题列表 | `问题系统/问题列表.md` |
| 问题详情 | `问题系统/问题/<问题名称>.md` |

## 表格格式

```markdown
| 日期 | 问题 | 状态 | 备注 |
| --- | --- | --- | --- |
```

## 操作步骤

1. 读取 `问题系统/问题列表.md` 当前内容。
2. 从用户输入提取：
   - **日期**：追加时自动填当天日期，格式 `YYYY-MM-DD`（无需用户提供）
   - **问题**：必填；用户描述的问题或待办
   - **状态**：新建时默认未完成 checkbox：`[ ]`；仅当用户明确表示已完成时用 `[x]`
   - **备注**：可选；未给出则留空
3. 用问题名称创建详情文件 `问题系统/问题/<问题名称>.md`（目录不存在则先创建）：
   - 文件名与问题名称一致；若含 Windows 非法字符 `\ / : * ? " < > |`，替换为 `-`
   - 若同名文件已存在，不要覆盖；在备注中注明「文件已存在」并仍写入列表链接
   - 新文件初始内容：

```markdown
# <问题名称>

```

4. 在表格顶部追加一行（插在表头分隔行 `| --- | --- | --- | --- |` 之后、现有数据行之前），不要改动已有行，不要改表头。
5. **问题**列写成相对路径 Markdown 链接（相对 `问题列表.md`），保证点击可跳转：

```markdown
[<问题名称>](问题/<问题名称>.md)
```

6. **状态**列写入 Markdown checkbox（表格单元格内直接写 `[ ]` 或 `[x]`，不要加列表符号 `-`）。
7. 保持 Markdown 表格对齐可读即可。

## 行模板

```markdown
| YYYY-MM-DD | [问题名称](问题/问题名称.md) | [ ] | 备注内容 |
```

## 示例

用户：`记录一下：登录页偶发白屏`

1. 新建 `问题系统/问题/登录页偶发白屏.md`：

```markdown
# 登录页偶发白屏

```

2. 在表格顶部追加（日期自动为当天，状态默认未完成）：

```markdown
| 日期 | 问题 | 状态 | 备注 |
| --- | --- | --- | --- |
| 2026-08-21 | [登录页偶发白屏](问题/登录页偶发白屏.md) | [ ] |  |
| （原有行保持不变） |  |  |  |
```
