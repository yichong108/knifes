# bl-wechat-post

把 `公众号系统` 里的指定文章打开到可复制状态，并打开微信公众号后台，方便用户粘贴发表。

## 何时启用

出现以下任一信号时启用：

- 明确点名 `bl-wechat-post`
- 「发表公众号」「发公众号」「发布图文」「去微信发这篇文章」
- 要求按文章名打开发布流程

## 硬性前置：文章名（不可跳过）

**没有文章名，禁止继续**（不打开后台、不打开文件、不猜标题）。

| 用户输入 | 处理 |
| --- | --- |
| 已给出文章名 / 《标题》 / 与列表一致的文件名 | 进入 Workflow |
| 只说「发一下」「帮我发公众号」等，无标题 | **只问一句**：请给出要发表的文章名（可对照 `公众号系统/文章列表.md`） |
| 文章名对不上已有文件 | 列出 `公众号系统/文章/` 中最接近的标题，请用户确认后再继续 |

澄清时每轮只问这一题；拿到明确文章名之前停在本步。

## 目标文件

| 用途 | 路径 |
| --- | --- |
| 文章列表 | `公众号系统/文章列表.md` |
| 文章正文 | `公众号系统/文章/<文章标题>.md` |
| 公众号后台 | `https://mp.weixin.qq.com/` |

## Workflow

- [ ] 确认文章名（缺失则追问并停止）
- [ ] 定位 `公众号系统/文章/<文章标题>.md`（必要时对照 `文章列表.md`）
- [ ] 打开本地文稿 + 打开公众号后台
- [ ] 中文简短告知下一步；不替用户登录、不代点「发表」

### 1. 定位文章

1. 用用户给出的文章名匹配 `公众号系统/文章/<文章标题>.md`。
2. 若文件名含非法字符替换（`\ / : * ? " < > |` → `-`），按同样规则匹配。
3. 找不到时：读 `文章列表.md`，给出接近项让用户选；仍无则停止，不要打开后台。

### 2. 打开发布所需界面

同一回合内完成：

1. **打开本地文稿**（便于复制）：用 MCP `cursor-app-control` 的 `open_resource`，URI 为该 `.md` 的 `file:///` 绝对路径（Windows 示例：`file:///D:/wishzhang/project/blackbox/公众号系统/文章/标题.md`）。
2. **打开公众号后台**：`open_resource` → `https://mp.weixin.qq.com/`  
   用户若给出完整 `https://mp.weixin.qq.com/...` 编辑页链接，则用该链接。
3. `open_resource` 失败时，Windows 兜底：

```powershell
Start-Process "<本地md的绝对路径>"
Start-Process "https://mp.weixin.qq.com/"
```

调用前先 `GetMcpTools` 再 `CallMcpTool`；不要改用其他无关站点。

### 3. 告知用户（模板）

```markdown
已准备发表《文章标题》：
- 本地文稿已打开：公众号系统/文章/<标题>.md
- 公众号后台已打开：https://mp.weixin.qq.com/

请在后台登录后新建图文，把正文粘贴进去再发表。
发表成功后告诉我，我可以帮你在文章列表里改状态/备注。
```

## 约束

1. **无文章名不动作**；禁止默认发「最新一篇」或列表第一篇。
2. 只打开已定位到的本地文稿 + 公众号相关 URL。
3. 不保存、不索要账号密码或扫码会话；不替用户点击后台「发表/群发」。
4. 不擅自改 `文章列表.md` 状态；仅当用户确认「已发表」时，才把对应行状态改为 `[x]`，备注可改为 `已发布`（或用户指定文案）。
5. 不擅自 `git commit` / `push`（除非用户另要 `bl-commit-push`）。

## 与其它 skill 的关系

- 写稿 / 选题 → `bl-wechat-write`
- 仅打开后台、不带文章 → `bl-wechat-open`
- **按文章名准备发表** → 本 skill `bl-wechat-post`

## 示例

**Example 1 — 缺文章名**

- Input: `bl-wechat-post`
- Output: 只追问文章名；不打开任何页面

**Example 2 — 带文章名**

- Input: `bl-wechat-post 把未读消息留了一整晚，我才发现自己在怕什么`
- Output: 打开对应 `.md` + `https://mp.weixin.qq.com/` → 按模板告知

**Example 3 — 用户确认已发**

- Input: `发完了`
- Output: 更新 `文章列表.md` 中该行状态为 `[x]`，备注改为已发布
